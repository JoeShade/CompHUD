## <img src="docs/assets/readme/icon-features.svg" alt="" width="20" height="20" align="absmiddle"> Features

- **Competitive captions** – A stripped down set of closed captions giving visual alerts for key sound cues, including Medic calls and off class voicelines.
- **Manual Über timer** - Start a countdown to estimate the earliest enemy Über and Kritz charge timings.
- **Ambassador crosshair overlay** - A fixed crosshair overlay for the Ambassador.
- **Adjustable viewmodel transparency** – Transparent viewmodels with customisable opacity
- **Customisable main menu shortcuts** - Set your own shortcut labels and console commands.

## <img src="docs/assets/readme/icon-installation.svg" alt="" width="20" height="20" align="absmiddle"> Installation

1. Download **CompHUD.zip** from the [Releases](https://github.com/JoeShade/CompHUD/releases).
2. Close TF2 and extract the ZIP.
3. Move the included `CompHUD` folder into `Team Fortress 2/tf/custom`.
4. Launch TF2.

See the [installation guide](docs/installation.md) for folder locations, timer setup and updating.
