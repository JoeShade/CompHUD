## Reporting an issue

Open a [GitHub issue](https://github.com/JoeShade/CompHUD/issues) or send a message on [Discord](https://discord.gg/N6QcgdsUrb). Include:

- A short description of the problem and the steps that reproduce it.
- A screenshot showing the problem.
- Any relevant console errors

## Making a change

1. Create a branch of the project.
2. Edit the relevant HUD resources.
3. Open a pull request describing what you have changed and why.
